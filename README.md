# MoBoR-Editor
Vibe Coding出来的一点小玩意，采用PyQt实现。目标是实现OpenBoR游戏制作的一站式编辑（虽然感觉这个目标很遥远）
- 总体而言，以修改各种txt配置文件为目标，但是是以可视化的方式，预先看到修改后的动画播放效果、场景布置效果和生敌怪的位置等，还可以时刻监视你做出来的修改反馈到txt文件上的结果。搭配以各种快捷键，将我认为有些麻烦的操作简单化。
- 晚些可能给出详细的功能介绍
- 业余时间更新，开发、测试缓慢请谅解。

An OpenBoR editor developed through vide coding. 
Lauguage: Python3 PyQt
Tool: WorkBuddy
Chinese version only, temporally.
